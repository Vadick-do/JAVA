# Бронирование ресурсов

Требуются JDK 21 или новее и Maven 3.9 или новее. Целевая версия Java — 21, кодировка — UTF-8.

Все команды выполняются из папки `kurs`:

```sh
cd '/Users/macbook/Desktop/универ/3курс/java/kurs'
```

На текущем компьютере команда `java` использует JDK 17, а Maven — JDK 27. Для одинаковой версии при сборке и запуске в текущем терминале:

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk/libexec/openjdk.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
java -version
mvn -version
```

На другом компьютере укажите путь к своему JDK 21 или новее. Эти команды меняют окружение только текущего терминала.

Сборка с очисткой предыдущего результата:

```sh
mvn clean verify
```

Запуск:

```sh
java -jar target/booking-backend-java-1.0-SNAPSHOT.jar
```

Программа выводит `Каркас приложения бронирования запущен.` и завершается. HTTP, подключение к БД и консоль управления пока не реализованы. JAR пока содержит только классы проекта; отдельный способ запуска с библиотеками потребуется при подключении HTTP и БД.

Просмотр библиотек, включая транзитивные зависимости:

```sh
mvn dependency:tree
```

Версии библиотек и плагинов зафиксированы в `pom.xml`. Зависимости загружаются из Maven Central; локальный кэш хранится в `.maven-repository` внутри `kurs` согласно `.mvn/maven.config`. Первый запуск требует доступа к сети. Результаты сборки находятся в `target`.

Предметных тестов пока нет. Команда `verify` проверяет сборку; тесты моделей будут добавлены вместе с моделями.
